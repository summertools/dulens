# dulens

**在终端中以清晰的树形结构或交互式界面探索磁盘占用。**

[English](README.md) | 简体中文

`dulens` 扫描文件和目录，直观展示空间去了哪里。它提供带尺寸、占比和条形图的彩色树形视图、全屏键盘交互浏览器，以及适合脚本和日志的纯文本布局。工具只读，无需配置。

## 概览

默认情况下，`dulens` 报告**已分配磁盘占用**（类似 `du`），在 Unix 上硬链接只统计一次，不跟随符号链接，并在每个给定路径下展示两层。常见用法：

- `dulens` —— 快速查看当前目录。
- `dulens -d 3 -a ~/projects` —— 包含文件并查看三层。
- `dulens -i /var` —— 交互浏览并逐层深入。
- `dulens --plain -d 3 .` —— 适合脚本或日志的稳定、无颜色输出。

当给出多个路径时，它们的尺寸会合并统计。每个路径作为一个顶层根显示，顶层占比使用合并后的总量。

## 特性

- 清晰的树形视图，包含尺寸、父级占比和八分之一字符精度的渐变条。
- 全屏交互浏览器，支持移动、翻页、排序和切换统计口径。
- 默认采用 `du` 风格的已分配磁盘占用，也可通过 `--apparent-size` 使用逻辑表观大小。
- 在 Unix 上，硬链接只统计一次；从不跟随符号链接。
- 可通过 `--one-file-system` 限制在单一文件系统内扫描。
- 可重复使用的 glob 排除规则，支持按条目名称或路径匹配。
- 宽度感知渲染，适配窄终端和宽字符（CJK）文件名。
- 打印前会转义文件名中的控制字符和 Unicode 双向文本控制符，恶意文件名无法注入终端转义序列或伪造布局。
- 纯文本模式不显示颜色、条形图、百分比、树形连接线，静态输出中也不显示标题。
- 如实反映退出状态：扫描错误会写入 stderr，并产生失败状态。

## 安装

`dulens` 是一个 Rust 二进制程序。需要较新的稳定版 Rust 工具链（Rust 1.88 或更新版本，edition 2024）和 Cargo。

从源码构建：

```bash
git clone https://github.com/summertools/dulens.git
cd dulens
cargo build --release
./target/release/dulens --help
```

安装到 Cargo 的 bin 目录：

```bash
cargo install --path .
```

或直接从仓库安装：

```bash
cargo install --git https://github.com/summertools/dulens.git
```

安装完成后，命令就是 `dulens`。

## 使用

```text
dulens [OPTIONS] [PATH]...
```

如果未提供路径，`dulens` 会扫描当前目录（`.`）。选项可以放在路径之前或之后。

```bash
dulens                         # 当前目录，深度 2
dulens -d 3 -a ~/projects      # 包含文件，深入三层
dulens -i /var                 # 交互式浏览器
dulens --plain -d 3 .          # 无任何装饰，适合管道
```

不使用 `-i` 时，结果写入 stdout，警告写入 stderr。使用 `-i` 时，`dulens` 会接管终端，直到你退出。

### 命令行选项

| 选项 | 默认值 | 说明 |
| --- | --- | --- |
| `PATH...` | `.` | 要检查的一个或多个路径。多个路径会合并统计，每个路径作为顶层根显示。 |
| `-d, --depth <N>` | `2` | 每个根路径下展示的子层级数。`0` 只显示根。 |
| `-a, --all` | 关闭 | 同时显示文件和目录。别名：`--files`。 |
| `-i, --interactive` | 关闭 | 启动全屏交互浏览器。 |
| `-p, --plain` | 关闭 | 干净的等宽布局；静态输出不显示标题、条形图、百分比、颜色和树形连接线。别名：`--simple`、`--clean`。 |
| `--apparent-size` | 关闭 | 统计文件的逻辑长度，而不是已分配的磁盘块。 |
| `--si` | 关闭 | 使用 1000 的幂（`kB`、`MB` 等）。与 `--bytes` 冲突。 |
| `--bytes` | 关闭 | 打印精确字节数。与 `--si` 冲突。 |
| `--color <WHEN>` | `auto` | 颜色模式：`auto`、`always` 或 `never`。 |
| `--no-color` | 关闭 | 无论 `--color` 如何设置都禁用颜色。 |
| `-s, --sort <KEY>` | `size` | 按 `size`（从大到小）或 `name`（A 到 Z，不区分大小写）排序。 |
| `-r, --reverse` | 关闭 | 反转最终排序顺序。 |
| `-x, --one-file-system` | 关闭 | 不跨入其他文件系统（仅 Unix）。 |
| `-E, --exclude <GLOB>` | 无 | 跳过匹配该 glob 的条目；可重复指定。 |
| `-q, --quiet` | 关闭 | 抑制扫描警告。退出状态仍会反映错误。 |
| `-h, --help` | | 打印帮助。 |
| `-V, --version` | | 打印版本。 |

说明：

- `--si` 使用 `kB`、`MB`、`GB` 等单位；默认使用二进制单位 `KiB`、`MiB`、`GiB` 等。
- `--bytes` 打印精确计数，例如 `1234 B`。
- `--no-color` 和 `--plain` 都会覆盖 `--color always`。
- `-i` 要求 stdin 和 stdout 都是终端；否则 `dulens` 会直接报错退出，而不是显示损坏的界面。

### 环境变量

| 变量 | 作用 |
| --- | --- |
| `NO_COLOR` | 只要设置了该变量（无论值是什么），`auto` 模式就会禁用颜色。 |
| `CLICOLOR` | `CLICOLOR=0` 时，`auto` 模式禁用颜色。 |
| `TERM` | `TERM=dumb` 时，`auto` 模式禁用颜色。值中包含 `256color` 时选择 256 色调色板。 |
| `COLORTERM` | 值中包含 `truecolor` 或 `24bit` 时选择 24 位真彩色。 |
| `COLUMNS` | stdout 不是终端时的输出宽度。小于 `20` 的值会被忽略；默认 `100`。 |

`NO_COLOR`、`CLICOLOR`、`TERM` 和 `COLORTERM` 只影响 `--color auto`（默认值），不会覆盖 `--color always`、`--plain` 或 `--no-color`。`COLUMNS` 仅在 stdout 不是终端时控制输出宽度。

| `PgUp` / `PgDn` | 翻一页 |
| `g` / `Home` | 跳到第一项 |

## 读懂输出

### 带装饰的树形视图

```text
dulens  311 KiB  ·  5 files  ·  5 dirs  ·  apparent

 240 KiB   77%  █████████▎░░  ├─ target/
```

- **标题行** —— 工具名、总大小、文件数、目录数；扫描多个路径时还会显示根数量；使用表观大小时显示 `apparent`；发生错误时显示错误数。
- **尺寸** —— 右对齐，列宽至少为七个字符。
- **占比** —— 条目大小占父级的百分比。顶层行使用所有根的合并总量。数值会四舍五入；很小的非零条目显示 `<1%`；显示条形图时，非零条目至少会得到一小段条形。
- **条形** —— 填充部分使用完整和部分块字符（八分之一格精度），并带有从青色到蓝色再到紫色的渐变。剩余部分以暗色显示。窄终端上会隐藏条形。
- **名称** —— 树形连接线加条目名称。

名称末尾的标记：

| 标记 | 含义 |
| --- | --- |
| `/` | 目录 |
| `@` | 符号链接 |
| `(hardlink)` | 额外的硬链接条目；其大小已计入另一个名称，因此此处显示为零 |
| `…` | 还存在更深层条目，但因当前深度限制未显示 |

名称按显示宽度计算，因此 CJK 等宽字符会被正确处理。放不下的名称会用 `…` 截断；普通名称从右侧截断，根路径从左侧截断，以保留最有辨识度的部分。

### 纯文本布局

纯文本模式只打印右对齐的尺寸、缩进和名称（以及名称标注）：

```text
 311 KiB  /tmp/dulens-demo/
 240 KiB    target/
 240 KiB      debug/ …
```

它适合管道、日志文件、diff 和截图，并且仍然遵循 `--depth`、`--all`、排序、排除规则和计算出的输出宽度。

## 大小如何计算

### 磁盘占用（默认）

在 Unix 上，每个条目的磁盘占用为 `st_blocks * 512`。这是已分配空间，而不是逻辑长度：稀疏文件实际占用的空间可能远小于其表观大小，目录也会包含自身的元数据块。这与 `du` 的默认行为一致。

在非 Unix 平台上，磁盘口径回退为文件长度。

### 表观大小

使用 `--apparent-size` 时，文件贡献其逻辑长度（`st_size`）。目录本身贡献零；目录总量是其中文件的总和。符号链接贡献链接文本的长度，因为不跟随链接。

### 硬链接

在 Unix 上，链接数大于 1 的文件会在整个扫描过程中按 `(设备号, inode)` 去重。最先遇到的条目保留大小；后续条目显示为零并带有 `(hardlink)` 标记。文件数仍会统计每个目录项，因此即使某个硬链接的尺寸不再重复计算，它仍会被计为一个文件。

### 符号链接与目录标识

从不跟随符号链接。它们会作为条目列出、计为文件，并标记 `@`。它们只贡献链接本身的大小。

目录通过 `(设备号, inode)` 标识，因此单次运行中不会重复遍历同一个目录，例如多个根路径重叠，或 bind mount 通过多个路径暴露同一个 inode 时。

### 文件系统边界

使用 `-x` / `--one-file-system` 时，设备号与根路径设备号不同的条目会被跳过。这适合扫描主目录或挂载点，同时避免进入其他文件系统。在无法获取设备标识的平台上，该选项不产生效果。

### 计数与错误

文件数包括所有非目录条目：普通文件、符号链接、硬链接条目和特殊文件。目录数包括所有被扫描的目录，也包括根目录本身。无法读取的条目会计入错误；它们不贡献任何大小，并会导致失败退出状态。

## 排除路径

`-E` / `--exclude` 可重复指定，使用 glob 语法：

- **不含**路径分隔符的模式（例如 `target` 或 `*.log`）匹配条目名称。
- **含**分隔符的模式（例如 `src/generated`）按基于所给根路径构造的条目路径匹配。还会隐式应用 `**/` 变体（绝对路径或已以 `**/` 开头的模式除外），因此同一模式通常可以在任意深度匹配。
- 末尾的 `/` 或 `\` 会被忽略，因此 `target/` 与 `target` 等价。
- `*` 不跨越路径分隔符；需要跨目录匹配时使用 `**`。
- 被排除的条目在扫描前就会跳过，因此其内容不会被统计。
- 排除规则作用于遍历过程中发现的条目。命令行中显式传入的路径始终会被扫描。
- 无效的 glob 会在扫描开始前报错，并以状态 1 退出。

示例：

```bash
dulens -E target -E node_modules -E .git .
dulens -a -E '*.log' .
dulens -E 'src/generated' .
dulens -E '**/cache' .
```

## 退出状态与警告

| 状态 | 含义 |
| --- | --- |
| `0` | 成功。输出管道被提前关闭时（例如被 `head` 关闭）也会返回该状态。 |
| `1` | 运行时失败：没有可读路径、任何扫描错误、无效排除模式、交互模式没有 TTY，或其他 I/O 错误。 |
| `2` | 参数解析器报告的命令行用法错误，例如未知选项，或同时指定 `--si` 与 `--bytes`。 |

警告以如下形式写入 stderr：

```text
dulens: warning: /path: Permission denied
```

每次运行最多打印 32 条详细警告。其余错误会汇总为 `N additional error(s) were suppressed`。`--quiet` 会抑制警告和汇总，但不会改变退出状态。如果完全无法扫描，仍会打印致命消息 `dulens: no readable paths`。

## 纯文本模式

`-p` / `--plain`（别名 `--simple` 和 `--clean`）产生干净的单色布局。静态输出不显示标题、颜色、条形图、百分比和树形连接线；每个条目一行，右对齐尺寸，名称按层级缩进。它仍然遵循深度、文件/目录显示、排序、排除规则和宽度限制。该模式在交互浏览器中也可用：标题保留，颜色、条形图和百分比不显示，当前行用 `>` 标记。

纯文本模式是脚本和可复现日志中最可预测的格式。即使同时指定 `--color always`，颜色也会被禁用。

## 颜色与终端宽度

颜色按以下顺序确定：

1. `--plain` 或 `--no-color` 禁用颜色。
2. 否则使用 `--color auto|always|never`。
3. 在 `auto` 模式下，只有 stdout 是终端、未设置 `NO_COLOR`、`CLICOLOR` 不为 `0`，且 `TERM` 不为 `dumb` 时才启用颜色。
4. 启用颜色后，根据 `COLORTERM` 和 `TERM` 选择 24 位、256 色或基础 ANSI 输出。

输出宽度按以下顺序确定：

- 如果 stdout 是终端，使用真实终端宽度。
- 否则，如果 `COLUMNS` 能解析为不小于 20 的数字，则使用该值。
- 否则默认宽度为 100 列。

在较窄的宽度下，`dulens` 会依次省略条形图、百分比列和树形缩进，最后用 `…` 截断名称，确保每一行都保持在计算出的宽度内。交互浏览器至少需要 40 列 × 8 行；低于该尺寸时会显示简短提示，而不是浏览器界面。

## 示例

| 命令 | 作用 |
| --- | --- |
| `dulens` | 当前目录，两层，仅目录 |
| `dulens -d 3 -a ~/projects` | 包含文件并深入三层 |

| `dulens --bytes --apparent-size -d 1 .` | 精确字节数，只显示一层 |

提前关闭管道也能正常工作：

```bash
dulens -a -q . | head -n 20
```

## 项目结构

| 路径 | 作用 |

| `src/format.rs` | 尺寸、百分比和条形图格式化；宽度感知截断；名称清理；调色板 |
| `src/render.rs` | 非交互树形渲染 |
| `src/tui.rs` | 交互式终端浏览器 |
| `tests/cli.rs` | 针对构建出的二进制文件的端到端 CLI 测试 |

## 平台说明与限制

- Linux 和 macOS 是主要目标平台。在非 Unix 平台上，磁盘口径回退为逻辑文件长度，硬链接去重和 `--one-file-system` 不可用。
- 扫描是顺序、单线程的。遍历非常大或远程的目录树可能需要较长时间。
- 结果是启动时的快照，不会实时更新。
- 工具是只读的：从不删除、移动或修改文件。
- 交互模式要求 stdin 和 stdout 都是终端，并且窗口至少为 40 × 8。
- 交互浏览器不支持鼠标、搜索、过滤或删除。
- 每次运行最多详细描述 32 条扫描警告。
- 命令行中显式传入的路径始终会被扫描，即使它们匹配排除模式。
